auditBugs:
  - title: "Express Error Handler Registration Sequence Bug"
    severity: "High Priority"
    file: "apps/api/src/app.ts (lines 33-38)"
    issue: "The global error handler `app.use(globalErrorHandler)` is registered BEFORE `/api` routes router configuration. Express fails to pass router errors to handlers if they are declared beforehand."
    impact: "Any unhandled service errors crash the Node engine or leak standard HTML traces to client browsers."
    fix: "Move `app.use(globalErrorHandler)` below `app.use(\"/api\", routes)`."
  - title: "Database Configuration vs Documentation Mismatch"
    severity: "Medium Priority"
    file: "database/prisma/schema.prisma vs 10-Database-Architecture.md"
    issue: "Technical documentation refers to MySQL relational engine implementation. However, the schema.prisma configuration uses postgresql relational engine mapping."
    impact: "If deploy environments use MySQL containers, the Prisma CLI generates migration failures and crashes on DB bootstrap."
    fix: "Standardize files and update docs to align on PostgreSQL deployment targets."
  - title: "Redundant Error Catching Block inside Controllers"
    severity: "Low Priority"
    file: "auth.controller.ts (and other controller scopes)"
    issue: "Controller routes manually catch execution exceptions and return status code JSON formats, bypassing middleware."
    impact: "Reduces benefits of central error tracking. Central logger (Pino) is bypassed and response structures are fragmented."
    fix: "Remove controller try-catch blocks and let errors bubble up to standard handlers."
  - title: "Empty Test Suite Assertions"
    severity: "Medium Priority"
    file: "tests/ subfolders"
    issue: "Integration, performance, and unit folders exist in folder lists but contain zero test suites or mocks."
    impact: "High regression risks on subsequent codebase changes."
    fix: "Establish basic test suites using Jest to cover tenant context validations."
